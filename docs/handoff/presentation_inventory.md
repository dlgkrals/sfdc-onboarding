## 4. 기준 점검

기준: 같은 레코드 채우기 = 저장 전 Flow / 입력받아 저장·제출 = Screen Flow / 다른 오브젝트 집계·판정 = 트리거·Apex / 여러 오브젝트를 찾아 보여 주기 = LWC + Apex / 사람 결정 = 승인 프로세스 / 외부 = Apex

| 기준                                      | 맞는 것                                                                                                  | 어긋나는 것 · 이유                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 같은 레코드 채우기 = 저장 전 Flow         | Case·Asset·WorkOrder·ProductItem·ProductTransfer 저장 전 Flow 5개                                        | **사업장 서비스센터는 트리거**(CustomerSiteTriggerHandler before insert/update). 이유(decision-log 도로명주소 9): 채우기와 함께 "주소 검색 없이 저장·매핑 없는 주소·센터만 변경"을 거부해야 하고, 시군구 5자리 → 시도 2자리 순서로 Custom Metadata를 찾는 규칙을 빠른 작업 저장(CustomerSiteAddressService)과 같은 코드로 써야 함                                                                                                                                   |
