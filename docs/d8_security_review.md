# D8 보안 점검 결과표

- 대상: 한결공조 AS 관리 (devorg, 브랜치 `feature/onboarding-d8`) · 점검일 2026-10-14 · 작성: Edwin(이학민), 점검 보조 Claude
- 기준: 커리큘럼 D8 보안 체크리스트 — with sharing 기본, `WITH SECURITY_ENFORCED`·`Security.stripInaccessible`·`USER_MODE`, 동적 SOQL 인젝션 방어, 서버 검증 필수, Named/External Credential(인증 분리), 트리거 내 콜아웃 → Queueable, 재처리·오류 기록, **권한을 줄인 사용자로 재현 → 수정 전/후**
- 범위: Apex 클래스 24개(테스트 제외, 2026-10-14 AccountController 삭제·VanStockService 추가 후), LWC 10개 + Aura 래퍼 2개, 권한 집합 4개(HG_CallCenter·HG_CenterManager·HG_Technician·HG_Admin), 조직 기본 공유(OWD)·공유 규칙, Named/External Credential 2쌍(HG_JusoApi·HG_ErpMock)
- 확인 방법 표기: **테스트** = Apex 테스트 메서드(`System.runAs` 테스트 사용자 포함) · **org** = 관리자로 실제 org 화면·조회 확인 · **Login As** = 실제 사용자(이서연·김병철·최민호)로 로그인해 확인
